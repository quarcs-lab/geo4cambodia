# geo: the spatial backbone

Every unit at every spatial scale has a **geo ID**. Administrative IDs follow the GADM 4.1 hierarchy and nest by prefix. Everything here except `scales.yaml` and `country_outline_web.geojson` is generated by `uv run geo4cambodia build geo` from `raw/boundaries/` and `raw/lookups/`.

| Scale | Units | ID pattern | Example | Notes |
| --- | --- | --- | --- | --- |
| `country` | 1 | `KH` | `KH` | |
| `gdl` | 17 | `KH-GDL-NN` | `KH-GDL-02` | Global Data Lab regions, unions of whole provinces |
| `province` | 25 | `KH-NN` | `KH-16` (Phnom Penh) | GADM order. ISO 3166-2 numbers differ (Phnom Penh is `KH-12` in ISO), so `shapeISO` is kept as a column |
| `district` | 202 | `KH-NN-NN` | `KH-16-01` | GADM level 2 |
| `commune` | planned | `KH-NN-NN-NN` | `KH-16-01-01` | reserved |
| `grid10k` | planned | `KH-G10K-rNNNcNNN` | `KH-G10K-r012c034` | reserved, 10 km cells in UTM 48N |

## Files

| File | Contents |
| --- | --- |
| `scales.yaml` | The scale registry: label, kind, parent, ID pattern, source, status |
| `units.csv` / `units.parquet` | Every unit: `geo_id`, `scale`, `name`, `parent_id`, the ids of every scale it nests in (`country_id`, `gdl_id`, `province_id`, `district_id`), the source keys (`gid` = GADM, `shapeISO`/`shapeID` = geoBoundaries, `GDLcode` = Global Data Lab), the names used by each source, and `area_km2` |
| `boundaries/<scale>.geojson` / `.parquet` | Polygons in CRS84 with `geo_id` and `name`. Provinces, GDL regions and the country are dissolved from the districts, so they nest exactly |
| `boundaries/country_outline_web.geojson` | A simplified outline used by the website's hero globe |
| `crosswalks/<from>__<to>.csv` | `geo_id_from`, `geo_id_to`, `weight_area` for every pair of nested scales (finer → coarser) |

```python
import geo4cambodia as geo
geo.units("province")             # names, parents and source keys
geo.boundaries("district")        # GeoDataFrame
geo.crosswalk("district", "gdl")  # district -> GDL region
```

Province names are harmonized in `raw/lookups/province_names.csv`, a hand-checked table that `geo4cambodia build` verifies against every source. The boundaries are for geo-statistical use only and do not represent an official definition of Cambodia's territorial boundaries.
