# Population, night-time lights, electricity-based GDP, NPP and PM2.5 (25 provinces, 1990–2023)

## Overview

This module is a long annual panel for **Cambodia's 25 provinces**. It aggregates five global gridded remote-sensing products to the province level: population, VIIRS-like night-time lights, electricity-based GDP, net primary productivity and PM2.5 concentration. Each `total_*` variable is the zonal sum of the grid values inside a province's boundary.

- **Geography:** 25 provinces (geoBoundaries ADM1)
- **Period:** 1986–2023 rows. Each variable has its own coverage (see below).
- **Categories:** Economy, Social, Environment
- **Rows:** 950 (25 provinces × 38 years)

## Files

| File | Form | Description |
| --- | --- | --- |
| `provinces25-1990-2023-pop-viirs-like-egdp-npp-pm25.csv` | long | One row per province-year (converted from the Stata file) |
| `provinces25-1990-2023-pop-viirs-like-egdp-npp-pm25.dta` | long | Original Stata file |

There is no boundary file for this module yet. `shapeID` is a [geoBoundaries](https://www.geoboundaries.org/) ADM1 identifier, so the panel can be joined to the geoBoundaries Cambodia ADM1 release.

## Variable Dictionary

| Variable | Description | Coverage | Source |
| --- | --- | --- | --- |
| **shapeISO** | ISO 3166-2 province code (e.g. `KH-12`) | — | geoBoundaries |
| **shapeName** | Province name | — | geoBoundaries |
| **shapeID** | geoBoundaries ADM1 identifier | — | geoBoundaries |
| **year** | Year | 1986–2023 | — |
| **total_GlobPOP_Density** | Zonal sum of gridded population density | 1990–2022 | Liu et al. (2024) |
| **total_GlobPOP_Count** | Zonal sum of gridded population count | 1990–2022 | Liu et al. (2024) |
| **total_VNL** | Zonal sum of NPP-VIIRS-like night-time lights | 2000–2023 | Chen et al. (2021) |
| **total_EGDP** | Zonal sum of revised real GDP from calibrated night-time lights | 1992–2019 | Chen et al. (2022) |
| **total_NPP** | Zonal sum of net primary productivity | 1986–2020 | Robinson et al. (2018) |
| **total_GHAP** | Zonal sum of PM2.5 concentration (GHAP) | 2017–2022 | Wei et al. (2023) |

> **Known issue:** in the current release `total_NPP` is **0 for every province and year**. Treat it as missing until the module is regenerated.

## Example Code

You can run the examples below in [![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/notebooks/empty.ipynb)

```python
import pandas as pd

url = "https://raw.githubusercontent.com/quarcs-lab/geo4cambodia/main/provinces25-env/provinces25-1990-2023-pop-viirs-like-egdp-npp-pm25.csv"
df = pd.read_csv(url)

# Night-time lights per person, 2000-2022
df["vnl_pc"] = df["total_VNL"] / df["total_GlobPOP_Count"]
df.pivot(index="year", columns="shapeName", values="vnl_pc").loc[2000:2022].plot(legend=False)
```

```stata
use "https://raw.githubusercontent.com/quarcs-lab/geo4cambodia/main/provinces25-env/provinces25-1990-2023-pop-viirs-like-egdp-npp-pm25.dta", clear
encode shapeISO, gen(pid)
xtset pid year
xtsum total_VNL total_EGDP total_GHAP
```
